## 3. Info 1–4: Kostenfunktion, fixe Kosten, Fixkostendegression, variable Kosten

:::info Info 1 · Die Kostenfunktion
Die Gesamtkosten lassen sich in fixe und variable Kosten teilen:

**Gesamtkosten = fixe Kosten + variable Stückkosten · Menge**

In Formelschreibweise: **Kg = Kf + kv · x**
:::

:::info Info 2 · Fixe Kosten
Fixe Kosten sind **unabhängig** von der Produktionsmenge. Sie bleiben auch bei schwankender Menge konstant. Man nennt sie auch „Kosten der Betriebsbereitschaft“: Sie fallen an, sobald eine Kapazität bereitgestellt wird, auch wenn nichts produziert wird.

Beispiele: kalkulatorische Abschreibungen, kalkulatorische Zinsen, Gehälter, Miete.
:::

:::info Info 3 · Fixkostendegression
Die fixen Gesamtkosten sind unabhängig von der Menge. Wird mehr produziert, **verteilen** sie sich auf mehr Stück: Die **fixen Stückkosten sinken** (degressiver Verlauf). Das nennt man auch das **Gesetz der Massenproduktion**: Je höher die Menge, desto niedriger die Stückkosten.

Sinkt die Menge, steigen umgekehrt die fixen Kosten je Stück.
:::

:::info Info 4 · Proportionale variable Kosten
Variable Kosten sind **abhängig von der Beschäftigung**. Ändert sich die Menge, ändern sich auch die variablen Gesamtkosten. Im Regelfall verhalten sie sich **proportional**: doppelte Menge, doppelte variable Kosten.

Bei proportionalen variablen Kosten bleiben die **variablen Stückkosten konstant**.

Beispiele: Rohstoffkosten, Löhne je Stück.
:::

:::achtung Typische Fehler
- **Fixe Stückkosten mit den fixen Gesamtkosten verwechseln:** Die fixen Gesamtkosten bleiben gleich, die fixen Stückkosten ändern sich mit der Menge.
- **Variable Stückkosten für Kosten „pro Monat“ halten** oder umgekehrt.
- **Behaupten, weniger produzieren senke die Stückkosten:** Es sinken nur die variablen Gesamtkosten. Die Stückkosten steigen, weil die Fixkosten auf weniger Stück verteilt werden.
:::
