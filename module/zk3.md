## 1. Ausgangssituation

:::situation Ausgangssituation: Eine besondere Anfrage
Der **Segelclub Förde e. V.** möchte für seine Regatta **50 Rucksäcke „Business Deluxe“** mit gesticktem Vereinswappen in einem Geschenkkarton bestellen.

**Merle Dahl** (Verkauf): „Das Wappen müssen wir sticken lassen, das kostet extra. Und der Karton auch.“

**Tobias Brandt** (Controlling): „Sondereinzelkosten also. Das Wappen: **6,50 €** je Rucksack, der Geschenkkarton: **2,20 €** je Rucksack. Rechne mit den üblichen Zuschlagssätzen.“
:::

## 3. Info: Sondereinzelkosten

:::info Info 3 · Sondereinzelkosten
**Sondereinzelkosten** sind Einzelkosten, die wegen **besonderer Produktions- oder Lieferbedingungen** nur für ein bestimmtes Produkt oder einen bestimmten Auftrag anfallen. Man rechnet sie dem Auftrag **direkt** zu, ohne Zuschlagssatz.

**Sondereinzelkosten der Fertigung:** z. B. Spezialwerkzeuge für diesen Auftrag, Sonderteile, Modelle, Lizenzgebühren für ein Design.

**Sondereinzelkosten des Vertriebs:** z. B. Spezialverpackung, außerordentliche Vertriebsprovision.

Das Kalkulationsschema wird erweitert:

| Position | Hinweis |
| --- | --- |
| MEK + MGK = MK | |
| FEK + FGK **+ Sondereinzelkosten der Fertigung** = FK | gehören zu den Herstellkosten |
| MK + FK = Herstellkosten | |
| + VwGK + VtGK | Basis: Herstellkosten (mit den Sonderkosten der Fertigung) |
| **+ Sondereinzelkosten des Vertriebs** | direkt zurechnen, ohne Zuschlag |
| = Selbstkosten | |
:::

:::aufgabe plus 25 Plus 2 · Preisverhandlung rückwärts
Die Montelli GmbH kalkuliert einen Großauftrag: Fertigungsmaterial 12.000,00 € · Fertigungslöhne 4.000,00 € · Sondereinzelkosten der Fertigung 1.500,00 € · Sondereinzelkosten des Vertriebs 1.500,00 € · MGK 10 % · FGK 250 % · VwGK 9 % · VtGK 6 % · Gewinn 5 %.

a) Ermittle den Angebotspreis (Barverkaufspreis).

b) Der Kunde ist bereit, **31.500,00 €** zu zahlen. Deshalb werden Maßnahmen geprüft: Das Fertigungsmaterial kann auf **11.000,00 €** und die Sondereinzelkosten des Vertriebs auf **1.250,00 €** sinken. Ermittle mit diesen Daten (gleiche Zuschlagssätze)

ba) die Materialkosten,
bb) die Selbstkosten, wenn der Gewinnzuschlag von 5 % beibehalten werden soll,
bc) die Herstellkosten und
bd) die Fertigungskosten, die dann insgesamt anfallen dürfen.

:::rechenraum 16
Rechenraum zu Plus 2
:::

:::hilfe 💡 Tipp zu b)
Rechne von hinten: Der Barverkaufspreis enthält 5 % Gewinn auf die Selbstkosten (also Selbstkosten = BVP : 1,05). Ziehe die Sondereinzelkosten des Vertriebs ab. Die verbleibenden Kosten enthalten VwGK und VtGK (zusammen 15 % der Herstellkosten).
:::
:::

:::achtung Typische Fehler
- **VwGK und VtGK auf die Herstellkosten ohne Sondereinzelkosten der Fertigung gerechnet:** Diese gehören zu den Herstellkosten.
- **Sondereinzelkosten des Vertriebs mit Zuschlag belegt:** Sie werden direkt addiert.
- **Sondereinzelkosten für einen einmaligen Auftrag auf alle Aufträge verteilt.**
:::
