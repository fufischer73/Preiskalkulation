## 3. Info 1–3: Deckungsbeitrag, Gewinnschwelle, mehrstufige Rechnung

:::info Info 1 · Der Deckungsbeitrag
Liegt der Verkaufspreis (e) über den variablen Stückkosten (kv), trägt die Differenz zur Deckung der fixen Kosten bei. Diese Differenz heißt **Stückdeckungsbeitrag (db)**. Er trägt mit jedem verkauften Stück zur Deckung der ohnehin anfallenden fixen Kosten bei.

**db = e − kv**

Der **Gesamtdeckungsbeitrag (DB)** ist die Differenz zwischen den Gesamterlösen (E) und den gesamten variablen Kosten (Kv):

**DB = E − Kv** oder **DB = db · x**

Beispiel (andere Zahlen): Eine Tasche kostet im Verkauf 60,00 €, die variablen Stückkosten betragen 24,00 €. Der Stückdeckungsbeitrag ist db = 36,00 €. Bei 200 Stück ist DB = 36,00 € · 200 = 7.200,00 €.
:::

:::info Info 2 · Die Gewinnschwelle (Break-even-Point)
Ein Unternehmen kann langfristig nur existieren, wenn seine Gesamtkosten durch die Gesamterlöse gedeckt werden. Die dafür nötige Menge heißt **Gewinnschwelle** oder **Break-even-Point**. An der Gewinnschwelle entsteht weder Gewinn noch Verlust: Die Erlöse reichen gerade aus, um alle variablen und alle fixen Kosten zu decken, der Gewinn ist null.

Liegt die Verkaufsmenge über der Gewinnschwelle, macht das Unternehmen Gewinn, darunter entsteht Verlust.

**Herleitung:** e · x = Kf + kv · x → (e − kv) · x = Kf → db · x = Kf → **x = Kf : db**

Beispiel (andere Zahlen): e = 60,00 €, kv = 24,00 €, Kf = 7.200,00 €. db = 36,00 €. x = 7.200 € : 36,00 € = 200 Stück. Ab 201 Stück entsteht Gewinn.

**Kontrollrechnung** mit der nächsten ganzen Menge: Erlös − Kosten bei 200 Stück = 12.000 € − (7.200 € + 4.800 €) = 0 €.
:::

:::info Info 3 · Mehrstufige Deckungsbeitragsrechnung
Bisher haben wir die fixen Kosten als **einen Block** behandelt (einstufige Deckungsbeitragsrechnung). Die **mehrstufige** Rechnung teilt die fixen Kosten nach ihrer Verursachung auf:

| Fixkostenschicht | Beispiele |
| --- | --- |
| Erzeugnisfixkosten | Patente, Lizenzen, Spezialwerkzeuge, Entwicklung |
| Erzeugnisgruppenfixkosten | Abschreibungen und Zinsen auf Mehrzweckanlagen, Meistergehälter |
| Bereichsfixkosten | Räume (Miete, Heizung), Funktionen (Lager, Verwaltung, Vertrieb) |
| Unternehmensfixkosten | Leitung, Beiträge, Rechnungswesen, Rechtsabteilung |

Aus dem Schema ergeben sich mehrere Deckungsbeiträge:

| Schritt | Rechnung |
| --- | --- |
| Nettoerlöse − variable Kosten | = **Deckungsbeitrag I** |
| − Erzeugnisfixkosten | = **Deckungsbeitrag II** |
| − Erzeugnisgruppenfixkosten | = **Deckungsbeitrag III** |
| − Bereichsfixkosten | = **Deckungsbeitrag IV** |
| − Unternehmensfixkosten | = **Erfolg** (Betriebsergebnis) |

So erkennst du, ob ein **Produkt**, eine **Gruppe** oder ein **Bereich** die ihm zurechenbaren Fixkosten deckt. Ein Produkt kann für sich wirtschaftlich sein, sein Bereich insgesamt aber nicht.
:::

:::achtung Typische Fehler
- **Mit den Selbstkosten statt mit den variablen Stückkosten rechnen**, wenn der Deckungsbeitrag gefragt ist.
- **Gewinnschwelle abrunden:** Bei 153,98 Stück gibt es erst bei 154 Stück Gewinn. Rechne auf ganze Stück **auf**.
- **Deckungsbeitrag mit Gewinn verwechseln:** Der Gewinn ist der Gesamtdeckungsbeitrag minus alle fixen Kosten.
:::
