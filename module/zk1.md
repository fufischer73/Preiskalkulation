## 1. Ausgangssituation

:::situation Ausgangssituation: Ein Angebot kalkulieren
Die **Hanseatische Bürodienst KG** aus Lübeck möchte ihren Mitarbeitenden zum Jahresende einen Rucksack schenken. Sie fragt bei der Montelli GmbH **40 Rucksäcke „Business Deluxe“** an und bittet um ein aussagekräftiges Angebot.

**Merle Dahl** (Verkauf): „Wir brauchen den Angebotspreis möglichst schnell. Denk daran: Alle betrieblich bedingten Kosten müssen berücksichtigt werden.“

**Tobias Brandt** (Controlling): „Eine Kostenträgerzeitrechnung kennst du schon. Jetzt geht es um die Stückrechnung für einen bestimmten Auftrag.“
:::

:::aufgabe basis 15 Aufgabe 3 · Den Angebotspreis berechnen
Berechne den **Angebotspreis (Listenverkaufspreis)** je Stück und für 40 Stück. Runde die Zeilen je Stück auf Cent.

| Angabe | Wert |
| --- | --- |
| Materialeinzelkosten (MEK) | 24,00 € je Stück |
| Fertigungseinzelkosten (FEK, Lohnkosten) | 36,00 € je Stück |
| Normalzuschlagssätze | MGK 5,0 % · FGK 130,0 % · VwGK 10,0 % · VtGK 5,0 % |
| Gewinnzuschlag | 20 % |
| Skonto | 2 % |
| Kundenrabatt | 8 % |
| Lieferbedingung | frei Haus |

Kalkulationsschema (je Stück und 40 Stück)

:::hilfe 💡 Tipp zum Aufbau
Material: MEK + MGK = MK. Fertigung: FEK + FGK = FK. Herstellkosten = MK + FK. Darauf VwGK und VtGK, dann Selbstkosten. Gewinn auf die Selbstkosten, dann Barverkaufspreis. Skonto und Rabatt rechnest du „im Hundert“ (siehe Info 1).
:::

:::

## 3. Info: Die Zuschlagskalkulation

:::info Info 1 · Zuschlagskalkulation
**Zeit- und Stückrechnung.** Die **Kostenträgerzeitrechnung** zeigt, welche Kosten für alle Produkte in einem Abrechnungszeitraum (meist ein Monat) angefallen sind. Die **Kostenträgerstückrechnung** (Kalkulation) berechnet die Selbstkosten für **ein Produkt oder einen Auftrag**, um daraus einen Preis abzuleiten.

**Prinzip der Zuschlagskalkulation.** Die **Einzelkosten** (Material, Fertigungslöhne) kann man dem Produkt direkt zurechnen. Die **Gemeinkosten** fallen für mehrere Produkte gemeinsam an. Sie werden mit **Zuschlagssätzen** auf die Einzelkosten bzw. die Herstellkosten verteilt. Als Zuschlagssätze nimmt man **Normalkosten** aus früheren Perioden.

| Schritt | Rechnung |
| --- | --- |
| Materialeinzelkosten (MEK) | |
| + Materialgemeinkosten (MGK) | MEK · MGK-Satz |
| = Materialkosten (MK) | |
| Fertigungseinzelkosten (FEK) | |
| + Fertigungsgemeinkosten (FGK) | FEK · FGK-Satz |
| = Fertigungskosten (FK) | |
| **Herstellkosten (MK + FK)** | |
| + Verwaltungsgemeinkosten (VwGK) | Herstellkosten · VwGK-Satz |
| + Vertriebsgemeinkosten (VtGK) | Herstellkosten · VtGK-Satz |
| = **Selbstkosten (SK)** | |
| + Gewinnzuschlag | Selbstkosten · Gewinnsatz |
| = Barverkaufspreis (BVP) | |
| + Skonto | BVP · Skonto : (100 − Skonto) |
| = Zielverkaufspreis (ZVP) | |
| + Rabatt | ZVP · Rabatt : (100 − Rabatt) |
| = **Listenverkaufspreis (LVP)** | |

**Skonto und Rabatt „im Hundert“.** Skonto und Rabatt gewährt der Kunde vom **Verkaufspreis**, den er zahlt: das Skonto vom Zielverkaufspreis, der Rabatt vom Listenverkaufspreis. Deshalb rechnest du den Zuschlag „im Hundert“: Du teilst durch (100 − Satz), nicht durch 100.

**Der Gewinnzuschlag** ist die Prämie für das unternehmerische Risiko. Er wird auf die Selbstkosten gerechnet.
:::

## 5. Plus

**Fertigungsmaterial lt. Stückliste:** Stoff 12,00 € · Reißverschlüsse 4,50 € · Polster 6,50 € · Zubehör 3,00 €

**Fertigungszeiten:** Fertigungsstufe I (Nähen) 40 Minuten, Fertigungsstufe II (Montage) 25 Minuten je Rucksack. Die Arbeitsstunde wird in Stufe I mit 36,00 € und in Stufe II mit 30,00 € verrechnet.

**Normalzuschlagssätze:** Material 8 % · Fertigung I 90 % · Fertigung II 70 % · Verwaltung 7 % · Vertrieb 5 %

:::achtung Typische Fehler
- **Skonto und Rabatt „auf Hundert“ statt „im Hundert“** gerechnet: Dann stimmt der Listenverkaufspreis nicht.
- **Verwaltungs- und Vertriebsgemeinkosten auf die Selbstkosten gerechnet:** Basis sind die Herstellkosten.
- **Gewinn auf den Barverkaufspreis gerechnet:** Der Gewinnzuschlag gilt für die Selbstkosten.
:::
